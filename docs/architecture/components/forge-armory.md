# forge-armory

**Purpose:** Git repo storing generated security artifacts organized by type.

## Current State

Scaffolded with empty directory structure. No artifacts generated yet.

- Repository: `git@github.com:nickpending/forge-armory.git` (private)
- Local clone: `~/development/projects/forge-armory/`
- Directories: skills/, agents/, tools/, commands/, plans/ (all with .gitkeep)
- .gitignore includes context.json exclusion (INV-005)
- README.md describes structure and usage

## Design

Flat structure organized by artifact type. The armory stores ALL artifact types Forge produces — Kit-eligible and armory-only alike. Kit registers a subset (skill, tool, agent, command). Automation configs (Justfiles, cron, n8n workflows) live in `tools/{name}/` alongside the tool they automate and are committed here but not Kit-registered.

Canonical directory structure (mirrors assembler Step 7):

| Artifact type | Path |
|--------------|------|
| Skills | `skills/{skill-name}/` |
| Tools + automation configs | `tools/{tool-name}/` |
| Agents | `agents/{role-slug}/` |
| Commands | `commands/{command-slug}/` |
| Plans | `plans/` |

Automation configs (Justfile, cron configs, n8n JSON) co-locate in `tools/{name}/` with their tool binary. They are armory-stored but not Kit-registered.

Artifacts are generated by forge-assembler and committed here. Not intended for manual editing.

## Connections

- **Written by:** forge-assembler (generates and commits artifacts)
- **Read by:** Kit CLI (artifacts registered via `kit add` reference paths in this repo)
- **Invariants:** INV-003 (all artifacts committed), INV-005 (no context.json)
